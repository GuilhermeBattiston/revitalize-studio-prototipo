# Revitalize Studio — protótipo de website

Protótipo não oficial de uma landing page para o **Revitalize Studio — Fisioterapia & Pilates**, no Sítio Cercado, Curitiba.

> Este projeto é uma demonstração independente. Não representa um site aprovado ou contratado pelo estabelecimento.

## Objetivo

Apresentar o Studio, organizar as modalidades divulgadas e transformar visitas em conversas para agendamento de aula experimental.

## Conteúdo e funcionalidades

- Página responsiva para celulares e computadores
- Botões que abrem diretamente o WhatsApp oficial
- Mensagem de agendamento previamente preenchida
- Modalidades de Pilates divulgadas nas plataformas públicas
- Comodidades e localização do estabelecimento
- Links para Instagram e rota no Google Maps
- Favicon e metadados para compartilhamento
- Proteção contra indexação enquanto o site não for aprovado

## Avisos importantes

- Textos, horários, modalidades, endereço e demais informações devem ser confirmados pelo Revitalize antes de uma publicação oficial.
- Algumas plataformas apresentam divergência entre os números **1114** e **1321** na Rua São José dos Pinhais. O protótipo utiliza **1321**, informado no Instagram, TotalPass e cadastro empresarial consultado.
- A imagem principal foi gerada por inteligência artificial e não representa o espaço real.
- O protótipo não apresenta depoimentos, resultados clínicos ou qualificações profissionais sem comprovação.
